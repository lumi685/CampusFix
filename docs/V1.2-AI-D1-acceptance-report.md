## 2. 实现与安全

新增 AI-01 路由，仅现有 AuthGuard 认证的 reporter/worker。角色来自数据库验证身份，管理角色明确403。AI层没有 Repository/SQL/数据库路径；现有 AuthGuard 仍需只读认证/授权摘要。聊天不创建工单、不改变业务数据库或 status_logs。

DeepSeek 非流式 Chat Completions 适配器，可信 `report-assistant-v1` 文本模板编译入后端，`thinking:disabled/max_tokens:512/stream:false`。不发工具、不执行模型指令、上游错误正文不读取/传播。WinHTTP 使用系统证书信任，不忽略 TLS 错误；禁止重定向/自动认证/Cookie；固定缓冲有界读取64KiB，安全响应最大1500字。并发4、每会话1，10/分钟、60/小时、进程200/小时。环境变量及分阶段超时细节见需求文档。

Vue新聊天页为 reporter/worker 开放，明确同意数据告知后发送。真实 API 客户端、逐条纯文本、忙碌/手动重试/清空/普通报修入口；无模板假成功。页内12条上下文、发送9000字上限；离开/pagehide/失去认证清除，迟到响应丢弃。不落地对话或 Token，不改旧报修页面。
